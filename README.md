# Pizzaria Novo Milenium — Loja Online

Sistema de pedidos online (mobile-first) para a Pizzaria Novo Milenium.

## Funcionalidades

- Cardápio completo com 27 pizzas
- Busca e categorias (Todas / Mais pedidas / Salgadas)
- Modal de produto: tamanho Grande/Broto, quantidade, observação
- Carrinho com +/− e remoção
- Checkout: entrega ou retirada
- Finalização via WhatsApp com mensagem formatada
